# Защита Кристалла

Небольшая браузерная игра в жанре **Tower Defense**, написанная на **TypeScript + Vite + Phaser 3**.

## Об игре

Игрок защищает кристалл от волн врагов. Возле пути врагов есть специальные слоты, куда можно ставить башни. Башни автоматически стреляют по врагам в радиусе действия. Цель — уничтожить всех врагов, не дав им дойти до кристалла.

| Действие | Что делает |
|---|---|
| **Клик по синему слоту** | Построить башню (стоит 50 золота) |
| **Наведение на башню** | Показать радиус её действия |
| **Клик по кнопке «▶ НАЧАТЬ ИГРУ»** | Запустить игру из меню |
| **Клик по кнопке «Начать заново»** | Вернуться в меню после победы/поражения |

Текущая версия — рабочий прототип с базовым геймплеем. В следующих итерациях будет реализовано:
- Система волн
- Анимация смерти врагов
- Анимация установки башни
- Разные типы башен и врагов
- Улучшение башен
- Продажа башен
